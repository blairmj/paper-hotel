# 학교 탈출

[학생용 게임 열기](https://blairmj.github.io/school-escape/)

하교 종이 울렸는데 학교 문이 잠겼습니다. 초등학교 5학년 학생이 교실에 흩어진 단서를 살펴보고, 일곱 개의 퍼즐을 풀어 학교 출입 시스템을 복구하는 1인칭 웹 방탈출 게임입니다.

## 처음 플레이할 때

1. 학생용 링크에서 **게임 안내 보기**를 누릅니다. 이동 방법과 일곱 교실의 순서를 확인합니다.
2. **우리 반 교실에서 시작**을 누르면 10분 타이머가 시작됩니다. 교실 바닥을 누르면 이동하고, 화면을 끌면 몸을 돌립니다. 물건을 누르면 가까이에서 조사할 수 있습니다.
3. 문 옆 장치에서 그 방의 문제를 확인합니다. 퍼즐을 풀면 문이 열리고 다음 교실로 자동 이동합니다. 마지막 컴퓨터실의 출입 패드를 복구하면 하교가 끝납니다.

**교실 순서**는 우리 반 교실 → 음악실 → 미술실 → 체육 준비실 → 도서실 → 과학실 → 컴퓨터실입니다.

같은 브라우저에서 학생용 링크를 다시 열어도 제목 화면부터 보입니다. 안내에서 **이어서 하기**를 누르면 풀던 교실로 돌아갑니다. 시작한 게임의 제한 시간은 자리를 비운 동안에도 흐릅니다. 시간이 끝났거나 하교를 마쳤다면 **지난 결과 보기**와 **처음부터 시작** 중 하나를 선택할 수 있습니다.

## 조작과 제한 시간

**↑ / ↓** 또는 W·A·S·D로도 걸을 수 있습니다. 마우스 휠 또는 **Ctrl + 더하기 / 빼기**로 확대·축소하고, **Ctrl + 0**으로 기본 배율로 돌아갑니다. 문 옆 장치를 클릭하거나 터치하면 문제를 다시 읽을 수 있습니다. 살펴본 단서는 **찾은 단서**에서 다시 확인할 수 있습니다.

학생용 게임의 제한 시간은 **출발부터 탈출까지 10분**입니다. 힌트 보기를 확인하면 30초가 차감됩니다. 마지막 10초에는 타이머가 빨갛게 점멸합니다. 시간이 끝나면 **다시 도전**을 눌러 우리 반 교실부터 다시 출발합니다. 연습 플레이의 진행 상황과 제한 시간은 현재 브라우저에 저장됩니다.

## 학급 수업과 기록

[교사용 대시보드](https://blairmj.github.io/school-escape/teacher.html)에서 교사 전용 코드 12자리를 입력하고 **새 학급 만들기**를 누릅니다. 교사 로그인은 8시간 유지되며 **로그아웃**으로 종료할 수 있습니다. **참여 링크 복사**로 받은 주소를 학생에게 보내세요. 학생은 링크에서 자기 출석번호를 입력하고 우리 반 교실에서 출발합니다. 참여 코드를 직접 입력할 때는 [학생 학급 참여](https://blairmj.github.io/school-escape/join.html)를 이용합니다.

학급으로 참여하면 교실을 방문한 순서, 방별 입실과 해결, 힌트·단서 확인, 재시도와 탈출 결과가 기록 DB에 저장됩니다. 담당 교사는 **학생별 플레이**에서 개별 풀이 과정을 확인하거나 **교실별 풀이**에서 평균 시간과 힌트 사용을 비교할 수 있습니다. **CSV 다운로드**는 해당 학급의 교실별 기록을 내려받습니다. 수업이 끝나면 **학급 관리**에서 새 참여를 마감할 수 있습니다.

게임이 끝나면 **학생 설문**에서 이번에 들어간 교실 중 가장 재미있었던 퍼즐, 가장 어려웠던 퍼즐, 가장 쉬웠던 퍼즐을 하나씩 고를 수 있습니다. 시간이 끝난 학생도 참여할 수 있습니다. 학급 응답은 교사용 **학생 설문** 탭에서 출석번호별 최근 응답 플레이 한 번을 집계합니다. 혼자 플레이한 응답은 해당 기기에 저장됩니다.

## 수정과 배포

이 저장소의 `main` 브랜치 루트가 GitHub Pages의 게시 폴더입니다. 로컬에서는 저장소 루트에서 `python -m http.server 8000`을 실행하고 브라우저에서 `http://localhost:8000/`을 엽니다. `index.html`과 `school-start.js`가 첫 화면과 안내를, `classroom.html`이 첫 교실을 엽니다. 일곱 교실은 JavaScript로 WebGL을 직접 제어해 그립니다. `webgl/`에는 카메라, 클릭 위치 판정, 셰이더, 메시와 텍스처 그리기 코드가 있습니다. 행렬 계산에는 [gl-matrix](./vendor/gl-matrix-LICENSE.txt), 구멍이 있는 도형의 삼각분할에는 [earcut](./vendor/earcut-LICENSE.txt)을 사용합니다.

`school-routes.js`는 정해진 교실 순서와 재입장할 때 이어서 풀 교실을 찾습니다. `school-puzzles.js`는 교실의 안내와 공·책 퍼즐을, `ct-devices.js`와 `ct-panels.js`는 나머지 장치의 규칙과 조작을 정의하고, `school-room.js`는 입력과 교실 이동을 처리합니다. `review-rooms.js`는 교실 목록, 진행 기록과 타이머를 관리합니다. 도서실·과학실 내부는 `specialty-interiors.js`에서, 음악실 합주석과 퍼즐은 `orchestra-room.js`와 `music-clock.js`에서 구성합니다.

교실 동선, 퍼즐, 제한 시간과 WebGL 클릭 판정은 `node --test`로 검사합니다.
