# 학교 탈출

[학생용 게임 시작](https://blairmj.github.io/school-escape/)

하교 종이 울린 직후 학교 출입 시스템의 연결이 끊깁니다. 시작 화면의 학교 배치도에서 일곱 교실의 순서를 확인하고 **시작하기**를 누릅니다. 우리 반 교실, 음악실, 미술실, 체육 준비실, 도서실, 과학실, 컴퓨터실 순서로 진행합니다. 퍼즐을 풀면 문이 열리고 다음 교실 이름을 잠깐 보여준 뒤 자동으로 이동합니다. 마지막 컴퓨터실에서 출입증 판독기를 고치고 새 카드로 확인하면 현관이 열립니다.

| 교실 | 학생이 푸는 퍼즐 | 관찰할 수 있는 컴퓨팅 사고력 |
| --- | --- | --- |
| 우리 반 교실 | 불빛 하나가 뒤집힌 4×4 판에서 잘못된 칸을 고칩니다. | 가로와 세로의 짝수 규칙을 함께 적용해 오류 위치를 찾습니다. |
| 음악실 | 피아노에서 투명 악보를 얻고 네 쌍의 바늘과 수의 관계를 찾아, 합주실 시계에 맞는 수를 다이얼에 입력합니다. | 여러 예에서 같은 규칙을 찾아 새로운 시계에 적용합니다. |
| 미술실 | 한 방울로 같은 열의 위·가운데·아래 칸을 칠합니다. 6×4 격자에서 일곱 방울로 작업대의 견본을 재현합니다. | 가장자리와 겹치는 칸을 고려해 선택의 결과를 예측하고 조합을 수정합니다. |
| 체육 준비실 | 회수 순서대로 공을 빼고, 매번 자리가 바뀐 공의 수를 문 옆 번호판에 네 자리 비밀번호로 입력합니다. | **배열과 상태 추적** · 공을 뺄 때마다 앞당겨진 자리를 파악하고 달라진 배열에서 다음 동작을 이어 가는지 봅니다. |
| 도서실 | 책 사이에 꽂힌 쪽지에서 대출 번호를 확인하고, 번호순으로 꽂힌 일곱 권 중 최대 세 권을 펼쳐 61번 책을 찾습니다. | **탐색 범위 좁히기** · 펼친 책의 번호와 목표를 비교해 다음 책을 고릅니다. 남은 범위의 가운데부터 보면 어느 위치든 세 번 안에 찾을 수 있습니다. |
| 과학실 | 흰 구슬 두 개에 이어 파란 구슬을 굴렸을 때 왼쪽·가운데·오른쪽 중 어느 컵에 들어갈지 예측합니다. | 구슬마다 어떤 갈림판의 상태가 바뀌는지 추적합니다. |
| 컴퓨터실 | 시험 카드로 두 판독기를 비교해 고장 난 방향을 고치고 새 카드로 재검사합니다. | 오류를 드러내는 입력을 고르고 수정 결과를 검증합니다. |

게임은 장치에 입력한 순서·선택·값을 검사합니다. 수업에서는 “다음 칸에 왜 그 값을 넣었나요?”처럼 한 가지 판단 근거를 물으면 학생이 사용한 사고 과정도 함께 확인할 수 있습니다.

화면을 끌어 둘러보고 바닥을 클릭해 이동합니다. **↑ / ↓** 또는 W·A·S·D로도 걸을 수 있습니다. 마우스 휠을 위로 굴리거나 **Ctrl + 더하기**를 누르면 교실을 확대하고, 휠을 아래로 굴리거나 **Ctrl + 빼기**를 누르면 축소합니다. **Ctrl + 0**으로 기본 배율로 돌아갑니다. 문 옆 장치에 다가가거나 마우스를 올리면 그 방의 문제가 보입니다. 클릭하거나 터치하면 문제를 다시 읽을 수 있습니다. 살펴본 단서는 **찾은 단서**에서 다시 확인할 수 있습니다.

학생용 게임의 제한 시간은 **출발부터 탈출까지 10분**입니다. 힌트 보기를 확인하면 30초가 차감됩니다. 마지막 10초에는 타이머가 빨갛게 점멸합니다. 시간이 끝나면 **다시 도전**을 눌러 우리 반 교실부터 다시 출발합니다. 연습 플레이의 진행 상황과 제한 시간은 현재 브라우저에 저장됩니다.

## 학급 수업과 기록

[교사용 대시보드](https://blairmj.github.io/school-escape/teacher.html)에서 교사 전용 코드 12자리를 입력하고 **새 학급 만들기**를 누릅니다. 교사 로그인은 8시간 유지되며 **로그아웃**으로 종료할 수 있습니다. **참여 링크 복사**로 받은 주소를 학생에게 보내세요. 학생은 링크에서 자기 출석번호를 입력하고 우리 반 교실에서 출발합니다. 참여 코드를 직접 입력할 때는 [학생 학급 참여](https://blairmj.github.io/school-escape/join.html)를 이용합니다.

학급으로 참여하면 교실을 방문한 순서, 방별 입실과 해결, 힌트·단서 확인, 재시도와 탈출 결과가 기록 DB에 저장됩니다. 담당 교사는 **학생별 플레이**에서 개별 풀이 과정을 확인하거나 **교실별 풀이**에서 평균 시간과 힌트 사용을 비교할 수 있습니다. **CSV 다운로드**는 해당 학급의 교실별 기록을 내려받습니다. 수업이 끝나면 **학급 관리**에서 새 참여를 마감할 수 있습니다.

게임이 끝나면 **학생 설문**에서 이번에 들어간 교실 중 가장 재미있었던 퍼즐, 가장 어려웠던 퍼즐, 가장 쉬웠던 퍼즐을 하나씩 고를 수 있습니다. 시간이 끝난 학생도 참여할 수 있습니다. 학급 응답은 교사용 **학생 설문** 탭에서 출석번호별 최근 응답 플레이 한 번을 집계합니다. 혼자 플레이한 응답은 해당 기기에 저장됩니다.

## 교실 검토

첫 화면과 교실 왼쪽 위의 **바로가기**에서 검토할 교실을 열 수 있습니다. [우리 반 교실 검토](https://blairmj.github.io/school-escape/index.html?review=1)와 개별 교실 주소도 검토 모드로 열립니다. 퍼즐을 풀면 아래 순서대로 다음 교실로 자동 이동하고, 컴퓨터실을 풀면 학교 현관이 열립니다. 이미 푼 교실은 바로가기에서 다시 풀 수 있습니다. 교실별 검토 제한 시간은 2분이며 검토 진행과 학생용 진행은 서로 다른 기록에 저장됩니다.

- [음악실](https://blairmj.github.io/school-escape/music.html)
- [미술실](https://blairmj.github.io/school-escape/art.html)
- [체육 준비실](https://blairmj.github.io/school-escape/sports.html)
- [도서실](https://blairmj.github.io/school-escape/library.html)
- [과학실](https://blairmj.github.io/school-escape/science.html)
- [컴퓨터실](https://blairmj.github.io/school-escape/computer.html)

## 수정과 배포

이 저장소의 main 브랜치 루트가 GitHub Pages의 게시 폴더입니다. 로컬에서는 이 폴더에서 `python -m http.server 8000`을 실행합니다. 일곱 교실은 JavaScript로 WebGL을 직접 제어해 그립니다. `webgl/`에는 카메라, 클릭 위치 판정, 셰이더, 메시와 텍스처 그리기 코드가 있습니다. 행렬 계산에는 [gl-matrix](./vendor/gl-matrix-LICENSE.txt), 구멍이 있는 도형의 삼각분할에는 [earcut](./vendor/earcut-LICENSE.txt)을 사용합니다.

`school-routes.js`는 정해진 교실 순서와 재입장할 때 이어서 풀 교실을 찾습니다. `school-puzzles.js`는 교실의 안내와 공·책 퍼즐을, `ct-devices.js`와 `ct-panels.js`는 나머지 장치의 규칙과 조작을 정의하고, `school-room.js`는 입력과 교실 이동을 처리합니다. `review-rooms.js`는 교실 목록, 진행 기록과 타이머를 관리합니다. 도서실·과학실 내부는 `specialty-interiors.js`에서, 음악실 합주석과 퍼즐은 `orchestra-room.js`와 `music-clock.js`에서 구성합니다.

교실 동선, 퍼즐, 제한 시간과 WebGL 클릭 판정은 `node --test`로 검사합니다.
