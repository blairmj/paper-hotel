# 학교 탈출

[학생용 게임 시작](https://blairmj.github.io/paper-hotel/)

하교 종이 울린 직후 학교 출입 시스템의 연결이 끊깁니다. 교실 배치도의 예상 풀이 시간을 보고 들를 교실을 3곳 이상 누르면, 우리 반 교실부터 컴퓨터실까지 이동 경로와 방문 순서가 지도에 바로 표시됩니다. 퍼즐을 풀면 문이 열리고 다음 교실 이름을 잠깐 보여준 뒤 자동으로 이동합니다. 마지막 컴퓨터실에서 출입 신호를 맞추면 현관이 열립니다.

| 교실 | 학생이 푸는 퍼즐 | 관찰할 수 있는 컴퓨팅 사고력 |
| --- | --- | --- |
| 우리 반 교실 | 칠판의 점검표를 읽고 복구 버튼 세 개를 차례로 누릅니다. | **순차 실행** · 화살표로 표현된 절차를 실제 동작 순서로 옮기는지 봅니다. |
| 음악실 | 변환 예시와 악보를 비교해 다이얼의 빈칸을 맞춥니다. | **패턴 인식과 부호화** · 같은 건반 번호가 연달아 나온 구간을 찾아 개수와 번호로 표현하는지 봅니다. |
| 미술실 | 인쇄·보관 기록을 비교하고 새 판화 도안에서 인쇄할 것만 고릅니다. | **논리적 조건과 일반화** · 테두리 유무와 점 개수에 관한 두 조건을 함께 적용하는지 봅니다. |
| 체육 준비실 | 공을 하나씩 빼고 남은 공 중 자리가 바뀐 개수를 고릅니다. | **배열과 상태 추적** · 공을 뺄 때마다 앞당겨진 자리를 파악하고 달라진 배열에서 다음 동작을 이어 가는지 봅니다. |
| 도서실 | 대출 메모를 확인하고, 번호순으로 꽂힌 일곱 권 중 최대 세 권을 펼쳐 61번 책을 찾습니다. | **탐색 범위 좁히기** · 펼친 책의 번호와 목표를 비교해 다음 책을 고릅니다. 남은 범위의 가운데부터 보면 어느 위치든 세 번 안에 찾을 수 있습니다. |
| 과학실 | 양팔저울 두 대에서 검은 구슬과 흰 구슬을 옮겨 보고, 문 다이얼에 지정된 구슬의 총무게를 입력합니다. | **등량 관계와 비례 추론** · 양쪽에서 같은 구슬을 덜었을 때도 균형이 유지되는지 관찰하고, 같은 구슬 묶음의 무게를 이용합니다. |
| 방송실 | 멈춘 방송 기록과 장치 안내표를 보고 믹서의 명령 순서를 고칩니다. | **디버깅** · 어느 상태에서 명령이 실패했는지 짚고 그 자리의 명령을 고쳐 작동시키는지 봅니다. |
| 컴퓨터실 | 신호 기록으로 분기표의 빈칸을 추론하고 새 신호 세 개의 목적지를 고릅니다. | **조건 분기** · 각 신호의 응답 여부에 따라 다음에 검사할 조건을 골라 결과까지 따라가는지 봅니다. |

게임은 장치에 입력한 순서·선택·값을 검사합니다. 수업에서는 “다음 칸에 왜 그 값을 넣었나요?”처럼 한 가지 판단 근거를 물으면 학생이 사용한 사고 과정도 함께 확인할 수 있습니다.

화면을 끌어 둘러보고 바닥을 클릭해 이동합니다. **↑ / ↓** 또는 W·A·S·D로도 걸을 수 있습니다. 문 옆 장치에 다가가거나 마우스를 올리면 그 방의 문제가 보입니다. 클릭하거나 터치하면 문제를 다시 읽을 수 있습니다. 살펴본 단서는 **찾은 단서**에서 다시 확인할 수 있습니다.

학생용 게임의 제한 시간은 **출발부터 탈출까지 10분**입니다. 힌트 사용을 확인하면 10초가 차감됩니다. 마지막 10초에는 타이머가 빨갛게 점멸합니다. 시간이 끝나면 **다시 도전**을 눌러 경로를 새로 고릅니다. 진행 상황과 제한 시간은 현재 브라우저에 저장됩니다.

## 교실 검토

첫 화면과 교실 왼쪽 위의 **바로가기**에서 검토할 교실을 열 수 있습니다. [우리 반 교실 검토](https://blairmj.github.io/paper-hotel/index.html?review=1)와 개별 교실 주소도 검토 모드로 열립니다. 교실별 검토 제한 시간은 2분이며 검토 진행과 학생용 진행은 서로 다른 기록에 저장됩니다.

## 수정과 배포

이 저장소의 main 브랜치 루트가 GitHub Pages의 게시 폴더입니다. 로컬에서는 이 폴더에서 `python -m http.server 8000`을 실행합니다. 여덟 교실은 JavaScript로 WebGL을 직접 제어해 그립니다. `webgl/`에는 카메라, 클릭 위치 판정, 셰이더, 메시와 텍스처 그리기 코드가 있습니다. 행렬 계산에는 [gl-matrix](./vendor/gl-matrix-LICENSE.txt), 구멍이 있는 도형의 삼각분할에는 [earcut](./vendor/earcut-LICENSE.txt)을 사용합니다.

`school-routes.js`의 복도 연결 정보는 안내도와 경로 생성에 함께 쓰입니다. 경로는 현재 위치와 방문한 교실을 함께 고려하는 너비 우선 탐색으로 구성합니다. `school-puzzles.js`는 교실의 퍼즐 자료와 풀이 규칙을 정의하고, `school-room.js`는 입력과 교실 이동을 처리합니다. `review-rooms.js`는 교실 목록, 진행 기록과 타이머를 관리합니다. 도서실·과학실·방송실의 내부는 `specialty-interiors.js`에서 구성합니다.

교실 동선, 퍼즐, 제한 시간과 WebGL 클릭 판정은 `node --test`로 검사합니다.
