# 학교 탈출

[학생용 게임 시작](https://blairmj.github.io/school-escape/)

하교 종이 울린 직후 학교 출입 시스템의 연결이 끊깁니다. 교실 배치도의 예상 풀이 시간을 보고 들를 교실을 3곳 이상 누르면, 우리 반 교실부터 컴퓨터실까지 이동 경로와 방문 순서가 지도에 바로 표시됩니다. 퍼즐을 풀면 문이 열리고 다음 교실 이름을 잠깐 보여준 뒤 자동으로 이동합니다. 마지막 컴퓨터실에서 출입증 판독기를 고치고 새 카드로 확인하면 현관이 열립니다.

| 교실 | 학생이 푸는 퍼즐 | 관찰할 수 있는 컴퓨팅 사고력 |
| --- | --- | --- |
| 우리 반 교실 | 불빛 하나가 뒤집힌 4×4 판에서 잘못된 칸을 고칩니다. | 가로와 세로의 짝수 규칙을 함께 적용해 오류 위치를 찾습니다. |
| 음악실 | 세 소리 카드와 두 반복 띠로 악보를 재생합니다. | 되풀이되는 작은 구간을 찾고 반복 안에 반복을 넣습니다. |
| 미술실 | 물감 세 방울로 벽화의 흰 칸을 채웁니다. | 상하좌우의 연결을 추적해 서로 분리된 영역을 찾습니다. |
| 체육 준비실 | 회수 순서대로 공을 빼고, 매번 자리가 바뀐 공의 수를 문 옆 번호판에 네 자리 비밀번호로 입력합니다. | **배열과 상태 추적** · 공을 뺄 때마다 앞당겨진 자리를 파악하고 달라진 배열에서 다음 동작을 이어 가는지 봅니다. |
| 도서실 | 대출 메모를 확인하고, 번호순으로 꽂힌 일곱 권 중 최대 세 권을 펼쳐 61번 책을 찾습니다. | **탐색 범위 좁히기** · 펼친 책의 번호와 목표를 비교해 다음 책을 고릅니다. 남은 범위의 가운데부터 보면 어느 위치든 세 번 안에 찾을 수 있습니다. |
| 과학실 | 연습대의 갈림판을 움직여 본 뒤 두 갈림판을 지나는 셋째 구슬의 출구를 예측합니다. | 구슬마다 어떤 갈림판의 상태가 바뀌는지 추적합니다. |
| 방송실 | 빛의 길이를 암호표로 해독해 믹서에 방송 순서를 입력합니다. | 연속 신호를 뜻이 있는 묶음으로 나누고 해독합니다. |
| 인쇄실 | 두 포스터를 스캔하고 인쇄하는 작업을 세 차례에 배치합니다. | 작업의 선후 관계를 지키면서 두 기계를 동시에 사용합니다. |
| 학생회실 | 접수증으로 입장 시각을 찾도록 공개할 두 항목을 고릅니다. | 목적에 필요한 데이터를 선택하고 이름 공개를 피합니다. |
| 컴퓨터실 | 시험 카드로 두 판독기를 비교해 고장 난 방향을 고치고 새 카드로 재검사합니다. | 오류를 드러내는 입력을 고르고 수정 결과를 검증합니다. |

게임은 장치에 입력한 순서·선택·값을 검사합니다. 수업에서는 “다음 칸에 왜 그 값을 넣었나요?”처럼 한 가지 판단 근거를 물으면 학생이 사용한 사고 과정도 함께 확인할 수 있습니다.

화면을 끌어 둘러보고 바닥을 클릭해 이동합니다. **↑ / ↓** 또는 W·A·S·D로도 걸을 수 있습니다. 마우스 휠을 위로 굴리거나 **Ctrl + 더하기**를 누르면 교실을 확대하고, 휠을 아래로 굴리거나 **Ctrl + 빼기**를 누르면 축소합니다. **Ctrl + 0**으로 기본 배율로 돌아갑니다. 문 옆 장치에 다가가거나 마우스를 올리면 그 방의 문제가 보입니다. 클릭하거나 터치하면 문제를 다시 읽을 수 있습니다. 살펴본 단서는 **찾은 단서**에서 다시 확인할 수 있습니다.

학생용 게임의 제한 시간은 **출발부터 탈출까지 10분**입니다. 힌트 사용을 확인하면 10초가 차감됩니다. 마지막 10초에는 타이머가 빨갛게 점멸합니다. 시간이 끝나면 **다시 도전**을 눌러 경로를 새로 고릅니다. 연습 플레이의 진행 상황과 제한 시간은 현재 브라우저에 저장됩니다.

## 학급 수업과 기록

[교사용 대시보드](https://blairmj.github.io/school-escape/teacher.html)에서 교사 계정으로 로그인하고 **새 학급**을 만듭니다. **참여 링크 복사**로 받은 주소를 학생에게 보내세요. 학생은 링크에서 자기 출석번호를 입력하고 교실을 골라 출발합니다. 참여 코드를 직접 입력할 때는 [학생 학급 참여](https://blairmj.github.io/school-escape/join.html)를 이용합니다.

학급으로 참여하면 선택한 경로, 방별 입실과 해결, 힌트·단서 확인, 재시도와 탈출 결과가 기록 DB에 저장됩니다. 담당 교사는 **학생별 플레이**에서 개별 풀이 과정을 확인하거나 **교실별 풀이**에서 평균 시간과 힌트 사용을 비교할 수 있습니다. **CSV 다운로드**는 해당 학급의 교실별 기록을 내려받습니다. 수업이 끝나면 **학급 관리**에서 새 참여를 마감할 수 있습니다.

## 수정과 배포

이 저장소의 main 브랜치 루트가 GitHub Pages의 게시 폴더입니다. 로컬에서는 이 폴더에서 `python -m http.server 8000`을 실행합니다. 열 교실은 JavaScript로 WebGL을 직접 제어해 그립니다. `webgl/`에는 카메라, 클릭 위치 판정, 셰이더, 메시와 텍스처 그리기 코드가 있습니다. 행렬 계산에는 [gl-matrix](./vendor/gl-matrix-LICENSE.txt), 구멍이 있는 도형의 삼각분할에는 [earcut](./vendor/earcut-LICENSE.txt)을 사용합니다.

`school-routes.js`의 복도 연결 정보는 안내도와 경로 생성에 함께 쓰입니다. 경로는 현재 위치와 방문한 교실을 함께 고려하는 너비 우선 탐색으로 구성합니다. `school-puzzles.js`는 교실의 안내와 공·책 퍼즐을, `ct-devices.js`와 `ct-panels.js`는 나머지 장치의 규칙과 조작을 정의하고, `school-room.js`는 입력과 교실 이동을 처리합니다. `review-rooms.js`는 교실 목록, 진행 기록과 타이머를 관리합니다. 도서실·과학실·방송실·인쇄실·학생회실의 내부는 `specialty-interiors.js`에서 구성합니다.

교실 동선, 퍼즐, 제한 시간과 WebGL 클릭 판정은 `node --test`로 검사합니다.
