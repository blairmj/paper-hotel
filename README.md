# 학교 탈출

[학생용 게임 열기](https://blairmj.github.io/paper-hotel/)

[203호 음악실에서 바로 시작하기](https://blairmj.github.io/paper-hotel/music.html)

음악실에서는 피아노의 투명 악보를 찾아 벽시계에 겹쳐 보고, 멈춘 시곗바늘을 읽어 문 옆의 숫자 바퀴 두 개를 맞춥니다. 처음 화면의 안내, 360° 탐색, 소지품, 도움말과 다시 풀기를 지원합니다.

음악실, 학교신문 편집실, 5학년 교실, 도서실, 미술실, 체육 준비실, 컴퓨터실, 과학실을 둘러보세요. 각 방에서 물건을 조사하고 퍼즐 하나를 풉니다. 정답을 맞히면 교실 문이 자동으로 열리면서 탈출이 기록됩니다. 열린 문 너머로 복도가 보이면 다음 교실로 이동할 수 있습니다.

화면을 끌어 둘러보고 W·A·S·D 또는 **한 걸음 ↑**로 이동합니다. 물건 이름을 눌러 조사하고 **단서 수첩**에서 다시 읽으세요. **학교 안내도**에서 교실을 선택할 수 있습니다. 진행 기록은 현재 브라우저에 저장됩니다.

## 수정과 배포

이 공개 저장소의 `main` 브랜치 루트가 GitHub Pages의 게시 폴더입니다. `index.html`, `school.css`, `rooms.js`(퍼즐과 단서), `scenery.js`(3D 공간), `game.js`(조작과 진행)를 수정해 푸시하면 같은 파일이 학생용 링크에 반영됩니다. 교실 미리보기 그림은 `rooms/`에 있습니다. 로컬에서는 이 폴더에서 `python -m http.server 8000`을 실행하세요.

3D 렌더링에는 [Three.js](./three-LICENSE.txt)를 사용합니다.
