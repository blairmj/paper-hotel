# 학교 탈출

[학생용 게임 열기](https://blairmj.github.io/paper-hotel/)

[203호 음악실에서 바로 시작하기](https://blairmj.github.io/paper-hotel/music.html)

203호 음악실은 양쪽 합주석 사이로 통로가 난 창문 없는 교실입니다. 정면에는 나무 피아노와 벽시계, 문 다이얼이 있고, 뒤쪽에는 악기장이 있습니다. 문 옆 다이얼을 누르면 두 자리 숫자를 돌릴 수 있습니다. 휠이나 오른쪽 아래 − / ＋ 버튼으로 0.5배에서 3배까지 확대·축소할 수 있습니다. 피아노에서 **악보 얻기**를 누른 뒤 벽시계에서 **악보 겹치기**를 누르고 두 자리 암호를 맞히면 문이 저절로 열립니다.

음악실, 학교신문 편집실, 5학년 교실, 도서실, 미술실, 체육 준비실, 컴퓨터실, 과학실을 둘러보세요. 각 방에서 물건을 조사하고 퍼즐 하나를 풉니다. 정답을 맞히면 교실 문이 자동으로 열리면서 탈출이 기록됩니다. 열린 문 너머로 복도가 보이면 다음 교실로 이동할 수 있습니다.

음악실에서는 바닥을 눌러 그 지점까지 걸어갈 수 있습니다. 화면을 끌어 둘러보고 W·A·S·D 또는 **한 걸음 ↑**로도 이동합니다. 물건 이름을 눌러 조사하고 **단서 수첩**에서 다시 읽으세요. **학교 안내도**에서 교실을 선택할 수 있습니다. 진행 기록은 현재 브라우저에 저장됩니다.

[음악실 디자인 시안](https://blairmj.github.io/paper-hotel/music.html?preview=music-room)은 학생용 게임과 같은 음악실을 처음부터 확인할 수 있는 별도 저장 공간을 사용합니다.

## 수정과 배포

이 공개 저장소의 `main` 브랜치 루트가 GitHub Pages의 게시 폴더입니다. `index.html`, `school.css`, `rooms.js`(퍼즐과 단서), `scenery.js`(3D 공간), `game.js`(조작과 진행)를 수정해 푸시하면 같은 파일이 학생용 링크에 반영됩니다. 교실 미리보기 그림은 `rooms/`에 있습니다. 로컬에서는 이 폴더에서 `python -m http.server 8000`을 실행하세요.

3D 렌더링에는 [Three.js](./three-LICENSE.txt)를 사용합니다.

203호는 `music.html`에서 바로 실행할 수 있습니다. `music-art.js`는 `rooms/music-art/`의 벽면 그림을 각각의 평면에 배치하고 시계·다이얼·여닫이문을 배치합니다. 시점 이동과 확대는 `music-world.js`, 단서와 암호 조작은 `music.js`에서 수정합니다.
