# 학교 탈출

[학생용 게임 열기](https://blairmj.github.io/paper-hotel/)

[203호 음악실에서 바로 시작하기](https://blairmj.github.io/paper-hotel/music.html)

203호 음악실은 양쪽 합주석 사이로 통로가 난 창문 없는 교실입니다. 정면에는 나무 피아노와 벽시계, 문 다이얼이 있고, 뒤쪽에는 악기장이 있습니다. 문 옆 다이얼을 누르면 두 자리 숫자를 돌릴 수 있습니다. 피아노에서 **악보 얻기**를 누른 뒤 벽시계에서 **악보 겹치기**를 누르고 두 자리 암호를 맞히면 문이 저절로 열립니다.

검토용으로 음악실과 다음 세 방을 플레이할 수 있습니다. 왼쪽 위 **바로가기**에서 진행 순서와 관계없이 방을 선택할 수 있습니다. 각 방의 잠금장치 하나를 풀면 문이 자동으로 열립니다.

- [미술실](https://blairmj.github.io/paper-hotel/art.html)에서 도장 뒷면의 자국과 뒤쪽 인쇄 순서 카드를 찾아 여섯 글자를 인쇄합니다.
- [체육 준비실](https://blairmj.github.io/paper-hotel/sports.html)에서 운동회 사진 속 공을 세고 옆 벽의 반납 순서에 맞춰 문 다이얼을 돌립니다.
- [컴퓨터실](https://blairmj.github.io/paper-hotel/computer.html)에서 앞뒤 화면의 입력·출력 기록을 비교하고 문 신호판의 픽셀을 켭니다.

바닥과 벽을 누르면 그쪽으로 걸어갑니다. 화면을 끌어 둘러보고 W·A·S·D로도 이동합니다. **↑ / ↓** 버튼의 한 번 이동 거리는 1.2m입니다. 새 세 방에서 살펴본 단서는 **찾은 단서**에서 다시 읽을 수 있습니다. 진행 기록은 현재 브라우저에 저장됩니다.

악보는 피아노와 상단 **내 악보**에서 다시 읽을 수 있습니다. 시계에 겹친 뒤에도 보관되며, 같은 브라우저에서 새로고침하면 이어서 플레이할 수 있습니다.

## 수정과 배포

이 공개 저장소의 `main` 브랜치 루트가 GitHub Pages의 게시 폴더입니다. 수정본을 푸시하면 같은 고정 주소에 반영됩니다. 로컬에서는 이 폴더에서 `python -m http.server 8000`을 실행하세요.

3D 렌더링에는 [Three.js](./three-LICENSE.txt)를 사용합니다.

203호는 `music.html`에서 바로 실행할 수 있습니다. `music-art.js`는 `rooms/music-art/`의 벽면 그림을 각각의 평면에 배치하고 시계·다이얼·여닫이문을 배치합니다. 시점 회전과 이동은 `music-world.js`, 단서와 암호 조작은 `music.js`에서 수정합니다.

세 새 방은 `school-room-art.js`에서 배경과 단서 그림을 배치하고 `school-room.js`에서 퍼즐과 저장을 처리합니다. 네 방은 이동·충돌·문 열림 코드와 팝업 스타일을 공유합니다. 교실 목록과 바로가기는 `review-rooms.js`에 있습니다.

새 배경은 내장 이미지 생성 도구로 제작했습니다. 공통 생성 조건은 창문과 사람이 없는 교실의 네 벽을 정면 입면도로 표현하고, 기존 음악실의 밝은 크림색 벽·나무 가구·차분한 녹색과 그림체를 맞추는 것입니다. 미술실에는 인쇄 작업대와 미술 재료장, 체육 준비실에는 벤치·장비함·매트, 컴퓨터실에는 컴퓨터 책상과 로봇 실습대를 요청했습니다. 생성한 네 벽 이미지를 분리한 최종 파일은 `rooms/art/`, `rooms/sports/`, `rooms/computer/`에 각각 `front.webp`, `back.webp`, `left.webp`, `right.webp`로 보관합니다.
