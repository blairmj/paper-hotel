# 학교 탈출

[학생용 게임 열기](https://blairmj.github.io/paper-hotel/)

[203호 음악실에서 바로 시작하기](https://blairmj.github.io/paper-hotel/music.html)

203호 음악실은 네 벽을 검정 흡음재로 마감한 창문 없는 음악 스튜디오입니다. 중앙에는 컴퓨터·건반·스피커가 있는 제작 작업석, 오른쪽에는 마이크와 이동식 흡음판이 있습니다. 피아노의 악보에서 찾은 규칙을 벽시계에 적용해 두 자리 암호를 맞히면 문이 저절로 열립니다. 악보를 얻은 뒤 벽시계에서 **힌트 보기**를 선택하면 악보를 겹쳐 볼 수 있습니다.

검토용으로 음악실과 다음 세 방을 플레이할 수 있습니다. 왼쪽 위 **바로가기**에서 진행 순서와 관계없이 방을 선택할 수 있습니다. 각 방의 잠금장치 하나를 풀면 문이 자동으로 열립니다.

- [미술실](https://blairmj.github.io/paper-hotel/art.html)은 옅은 청록색 미장벽·밝은 회색 바닥과 공동 작업대 2개, 의자 8개, 세척대·건조대·재료장을 배치했습니다. 작업대의 도장 뒷면과 게시벽의 인쇄 순서 카드를 찾아 여섯 글자를 인쇄합니다.
- [체육 준비실](https://blairmj.github.io/paper-hotel/sports.html)은 낮은 콘크리트 천장 아래 주황·파랑 양면 라커 세 줄이 있습니다. 서로 다른 통로의 열린 라커에서 운동회 사진과 반납 순서를 찾아 문 다이얼을 돌립니다.
- [컴퓨터실](https://blairmj.github.io/paper-hotel/computer.html)은 흰 패널 벽과 파란 문, 가운데 통로 양쪽에 나란히 놓인 컴퓨터 24대가 있습니다. 앞벽의 기록과 뒤쪽 자리의 모니터를 비교해 문 신호판의 픽셀을 켭니다.

바닥과 벽을 누르면 그쪽으로 걸어갑니다. 화면을 끌어 둘러보고 W·A·S·D로도 이동합니다. **↑ / ↓** 버튼의 한 번 이동 거리는 1.2m입니다. 새 세 방에서 살펴본 단서는 **찾은 단서**에서 다시 읽을 수 있습니다. 진행 기록은 현재 브라우저에 저장됩니다.

악보는 피아노와 상단 **내 악보**에서 다시 읽을 수 있습니다. 시계에 겹친 뒤에도 보관되며, 같은 브라우저에서 새로고침하면 이어서 플레이할 수 있습니다.

각 방의 제한 시간은 **2분**이며 오른쪽 위에 표시됩니다. 힌트 확인창에서 **확인**을 누르면 10초가 차감됩니다. 마지막 10초 동안 타이머가 빨갛게 점멸합니다. 시간이 끝나면 **다시 도전**으로 새로 시작합니다. 새로고침해도 남은 시간이 초기화되지 않으며, 정답을 맞히면 타이머가 멈추고 문이 자동으로 열립니다.

네 방의 바닥은 기존 19 × 13.54m의 정확히 절반인 약 13.435 × 9.574m입니다. 가구 크기와 눈높이 1.55m는 유지했습니다. 공간 안에 배치된 가구와 벽은 클릭 이동의 충돌 경계로 사용합니다.

## 수정과 배포

이 공개 저장소의 `main` 브랜치 루트가 GitHub Pages의 게시 폴더입니다. 수정본을 푸시하면 같은 고정 주소에 반영됩니다. 로컬에서는 이 폴더에서 `python -m http.server 8000`을 실행하세요.

3D 렌더링에는 [Three.js](./three-LICENSE.txt)를 사용합니다.

203호는 `music.html`에서 바로 실행할 수 있습니다. 승인된 음악실·미술실 배치와 마감은 `school-interiors.js`에서 정의합니다. 직사각형 네 벽과 가구, 흡음 천장·경사 천장, 잠금장치와 여닫이문을 실제 WebGL 공간에 배치합니다. 시점 회전과 이동은 `music-world.js`, 음악실 단서와 암호 조작은 `music.js`에서 수정합니다.

다른 세 방은 `school-room-art.js`에서 방을 선택하고 `school-room.js`에서 퍼즐과 저장을 처리합니다. 체육 준비실의 라커와 컴퓨터실의 좌석은 `sports-computer-interiors.js`에서 배치합니다. 네 방은 이동·충돌·문 열림 코드와 팝업 스타일을 공유합니다. 교실 목록·바로가기·타이머는 `review-rooms.js`에 있습니다.

배치의 단서 접근 경로와 타이머의 새로고침·시간 종료·재시작 검사는 `node --test tests/interiors.test.cjs`로 실행합니다.

`interior-artwork.js`는 `rooms/interiors/`에 저장한 승인 시안에서 벽·바닥·천장과 가구에 쓸 질감을 읽습니다. 시안에 나온 스피커, 작업 화면, 코르크 게시판 같은 부분은 해당 물건의 3D 표면에 입힙니다.
